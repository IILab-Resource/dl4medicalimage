## 一、这门课要解决的真问题

医学影像人工智能听起来离新生很远,但它面对的问题非常具体:

一个急诊病人做完 CT,放射科医生要先花时间**读片**(判断发生了什么),再花时间**勾画**(把器官和病灶的边界量出来)。放疗计划、手术导航都依赖第二步;疗效随访要比较同一个器官在半年后变没变大,依赖第三步。

这三步 —— **读片、勾画、对比** —— 就是这门课要一条一条走完的路。

我们不从"模型结构图"开始,而从**临床问题**开始:

| 临床问题            | 算法任务       | 阶段  |
| --------------- | ---------- | --- |
| 片子太多,先分诊        | 图像分类       | 阶段一 |
| 勾画太慢            | 图像分割(2D)   | 阶段一 |
| CT 是几十层切片,不是一张图 | 图像分割(3D)   | 阶段二 |
| 几十个器官不可能逐个建模    | 多类分割       | 阶段二 |
| 不同序列给出不同答案      | 多模态多标签分割   | 阶段三 |
| 小病灶像一根针,找不到     | 目标检测       | 阶段三 |
| 两次复查对不上         | 图像配准       | 阶段三 |
| 病理切片十万像素宽       | 弱监督学习      | 阶段三 |
| 需要连续的风险分数       | 回归预测       | 阶段三 |
| 有经验的医生只有一个小时    | 自监督 / 生成模型 | 阶段四 |

## 三、阶段〇 · D1 · 影像科的一天

### 问题:医生的时间到底花在哪?
我们先不写代码。打开一个真实的 CT 数据集,看清楚"一个病人"在磁盘上究竟是什么样子。

### 要学的内容

- **医学影像的物理成像**:X 光投影成像、CT 断层重建、MRI 磁共振、超声、病理染色 —— 五种模态的图像含义完全不同
- **CT 的 HU 值**:为什么取值跨越 −1000(空气)到 3000(骨),为什么看片要有"窗宽窗位"的概念
- **四种数据格式**:DICOM(医院内部原始格式,一个序列几百张)、NIfTI(科研通用格式,三维体数据)、PNG/JPEG(降维后的二维图)、WSI(病理全切片,多分辨率金字塔)
- **一个真实体数据长什么样**:形状、体素间距、方向、标签取值

### 现场实测
| 数据集 | 样本量 | 形状 | 体素间距 |
|---|---|---|---|
| MedNIST | 58,954 张 | 64 × 64 二维灰度 | — |
| 脾脏 CT(核心) | 41 例训练 + 20 例测试 | 512 × 512 × 31~168 | 层内 0.61–0.98 mm,层厚 1.3–8.0 mm |
| 全身多器官 CT | 约 22 例 | 三维 | — |

**第一个震撼点**:一脾脏 CT 单例就有 **4400 万个体素**。它在磁盘上不是"一张大图",而是三维空间中一小块组织。

**第二个震撼点**:层内间距 0.7 mm、层厚 5 mm —— **同一份数据的 Z 方向分辨率比 XY 方向差了近 7 倍**。这个数字将在阶段二决定你所有的工程决策。

### 交付物
- 一个统一的影像读写器(能打开 PNG / NIfTI / DICOM,并打印形状、方向、物理尺度)
- 脾脏 CT 数据卡

### 学完之后能干什么
拿到任何一份医学影像数据,你知道怎么打开它、怎么判断它的方向和物理尺度、它的"一个像素"在真实世界里有多大。**这是所有后续工作的地基。**

## 四、阶段一· 让机器看懂「这是什么片子」

### 问题 1:影像科的分诊台 —— 先分诊,再看片

**临床场景**:急诊一夜几百张 CT,医生要先判断"哪张必须马上看"。

**技术挑战**:
- 类别极不均衡:真正的急症片子在数据里可能只占 2%
- 图像很小(64 × 64),甚至比手写数字还小
- 同一征象在不同厂商设备上表现不一样 → 泛化困难

**要学的内容**:

| 模块 | 具体内容 |
|---|---|
| 训练循环 | 优化器、调度器、早停、梯度裁剪、混合精度、断点续训、随机种子固定 |
| 模型 | 从零实现 CNN 与残差网络 |
| 评估 | 混淆矩阵、精确率、召回、F1、ROC-AUC、PR-AUC;阈值怎么选 |
| 类别不平衡 | 重采样、加权交叉熵、Focal Loss、阈值调整 —— 四种手段何时用哪个 |
| 数据增强 | 几何(裁剪/翻转/旋转/缩放)与强度(噪声/gamma/亮度/对比度) |
| **医学禁区** | 哪些增强在医学上是错的:左右器官镜像、特定解剖结构的旋转 |

**为什么强调 PR-AUC 而不是 ROC-AUC**:正负样本比例悬殊时,ROC-AUC 会显得过于乐观。急诊分诊属于典型的不平衡场景。

**数据**:
- MedNIST(58,954 张 64×64 六类)
- Rxrx1 子集(1,200 样本,四类细胞,多通道显微图像 —— 用于理解"多通道"数据)

**交付物**:2D 分类 baseline + 一份诚实的评估报告(必须包含混淆矩阵与不平衡分析)

**学完之后能干什么**:为任意影像分类任务搭建规范的训练与评估流水线;拿到一个模型能判断它错在哪、是否值得上线。

---

### 问题 2:勾画器官边界太耗时

**临床场景**:放疗计划、手术导航都依赖器官勾画,人工勾一个器官十几分钟,一天下来只能处理几个病人。

**技术挑战**:
- 分割的输出是**连续的像素集合**,不是类别标签
- 前景与背景极度不平衡(器官可能只占画面 5%)
- 边界本身就有争议:两位医生勾的边界不完全一样

**要学的内容**:

- **U-Net 结构**:编码器-解码器 + 跳连为什么有效(细节信息为什么不能丢)
- **分割损失**:交叉熵 vs Dice 为什么需要 Dice;Dice 与 IoU 的关系;**空前景的陷阱**(一个全是背景的 patch 会让 Dice 损失失效)
- **分割评估**:Dice、IoD;以及"高 Dice 不等于分割好"的原因
- **为什么要 Dice**:分类用交叉熵,分割用 Dice,这个选择不是随意的

**数据**:
- MedNIST 构造的前景分割任务
- 内镜器械分割(150 帧,类别极不平衡 + 小目标)

**交付物**:从零实现的 2D U-Net + Dice 损失

**学完之后能干什么**:实现一条可用的二维器官/病灶自动勾画流水线,并解释它为什么有效。

## 五、阶段二· 让机器看懂「器官有多大、在哪里」★核心阶段



### 问题 3:CT 是一堆切片,不是一张图

**临床场景**:要判断"脾脏是否肿大",必须把几十层切片串起来看整体形态,而不是只看单层。

**技术挑战(全部来自真实数据)**:

1. **内存爆炸** —— 单例 512 × 512 × 168 = 4400 万体素。整卷送进网络,普通显卡直接 OOM
2. **各向异性** —— 层内 0.61–0.98 mm,层厚 1.3–8.0 mm,最坏情况差近 10 倍。强行各向同性 resize 会破坏解剖结构
3. **数据极少** —— 只有 41 例训练数据,每例只有一张完整标注
4. **前景极度稀疏** —— 脾脏通常只占 0.1%–1% 的体素
5. **病人级评估** —— 切出来的 patch 之间高度相关,不能当成独立样本评估

**要学的内容**(本课程的核心清单):

| 模块 | 具体内容 | 为什么必须学 |
|---|---|---|
| NIfTI 解剖学 | header、dim、pixdim、affine、方向码(RAS/LPS) | resize 后不同步 affine,后续所有几何操作全错 |
| 强度处理 | 窗宽窗位、CT 专用归一化 | CT 直接做 z-score 会破坏组织对比度关系 |
| 重采样 | 各向异性 → 各向同性的条件与代价 | 什么时候该重采、什么时候不该 |
| **Patch 采样** | 随机采样 / 前景感知采样 / 均衡采样 | **小目标任务里,采样策略比网络结构影响更大** |
| 3D U-Net | 从零实现,含残差块与瓶颈 | 显存预算 → 反推网络宽度与深度 |
| 显存工程 | 混合精度、梯度检查点、梯度累积 | 让训练跑得起来是前提 |
| 分割损失 | Dice / Tversky / Focal-Tversky / Lovász、深监督 | 空前景、稀疏前景下的损失行为差异 |
| **滑窗推理** | 窗口、步长、高斯加权融合 | 整卷推理跑不动,滑窗是唯一可行方案 |
| 后处理 | 阈值、最大连通域、形态学 | 去掉孤立假阳性,直接决定最终指标 |
| **病人级评估** | case-level vs patch-level 聚合 | **最常见的错误就在这里** |
| 训练工程 | warmup+cosine 调度、EMA、EMA、分布式、profiling | 定位数据瓶颈还是算力瓶颈 |
| 性能分析 | 用 profiler 拆解数据/前向/反向/通信耗时 | 别把 I/O 慢误判成算力不足 |

**数据**:脾脏 CT(41 例训练 + 20 例测试,各向异性三维体数据)

**交付物**:
- 病人级 Dice ≥ 0.90 的三维分割系统
- 训练速度优化前后对比
- **错误案例分析**:至少 5 例失败样本的成因(标注质量 / 边界模糊 / 病灶过小)

**学完之后能干什么**:
独立完成一个可上线的医学三维分割系统。遇到显存不够、速度不够、数据泄漏时知道该怎么办。

> **达标线说明**:该数据集公开结果常在 0.90–0.95。**学生达不到时,能准确说清卡在哪一步(数据管线 / 模型容量 / 损失 / 推理)比刷高指标更重要**

### 问题 4:104 个器官,不可能一个个建模

**临床场景**:放疗剂量计算、手术导航需要全身器官的位置。

**技术挑战**:
- 类别极端不平衡:脾脏几万体素,某些器官只有一百来个体素,差 1000 倍
- 器官大小形态差异巨大,统一尺度的网络会漏掉小器官
- 104 个类别不可能为每个类别单独训练一个模型

**要学的内容**:
- 单网络多类分割的一体化设计
- 类别平衡损失与多任务权衡
- "先粗后细"两阶段策略(先定位再精修)
- 多类评估协议:逐类别 Dice 报表、总体 Dice、失败类别归类

**数据**:全身多器官 CT 样本(约 22 例,104 个类别)

**交付物**:单网络多器官分割 + 逐类别评估表

**学完之后能干什么**:面对"要同时分割几十个目标"的需求,知道如何拆解问题、设计模型与评估方式。

## 六、阶段三· 让机器解决真实临床难题

这一周横向拓展五类任务。**目的不是学五个新模型,而是检验你能否把已有的核心能力迁移到新问题。**

---

### 问题 5:脑肿瘤的边界,不同序列给出不同答案

**临床场景**:胶质瘤的"强化区 / 浸润区 / 水肿区"要靠 T1 增强、FLAIR 等多个序列综合判断,单看任何一个都会出错。

**技术挑战**:
- 四个模态采集于不同时刻,存在轻微错位,拼接后可能自相矛盾
- 标签是**嵌套的**(强化区 ⊂ 浸润区 ⊂ 全肿瘤),不是四个互斥类别
- 评估要同时看三个嵌套区域,而不是简单平均

**要学的内容**:
- 多模态数据的组织方式(多通道输入 vs 多模型融合)
- 模态间错位的检测与处理
- 嵌套标签的训练策略与聚合评估
- **Transformer 分割**:从零实现注意力块与窗口注意力,再实现 UNETR 与 SwinUNETR
- **从分类预训练权重迁移**:patch 嵌入层的尺寸不匹配问题怎么解决

**数据**:脑肿瘤多模态 MRI(四序列)
**交付物**:多模态多标签分割 + 嵌套区域评估
**学完之后能干什么**:处理多模态影像的融合与评估 —— 这是脑肿瘤、阿尔茨海默、帕金森等方向共同的基础能力。

---

### 问题 6:小的病灶像一根针,分割救不了

**临床场景**:肺结节直径只有几毫米。先要"找到它",再去"量它" —— 用分割做目标检测会直接漏掉。

**技术挑战**:
- 结节占体积极小,先分类再分割会漏检
- 三维候选框的生成与去重比二维复杂
- 检测任务的指标不是 mAP,而是 FROC(对每个假阳性数给出敏感度)

**要学的内容**:
- 无锚框三维检测(中心点/FCOS 思路)
- 三维候选框的编码与解码
- 三维非极大值抑制
- 候选点生成(肺结节经典做法)
- FROC 曲线与 AUC 解读

**数据**:肺结节 CT 样本(标注为三维候选框)
**交付物**:三维检测器 + FROC 曲线
**学完之后能干什么**:把"检测 → 测量 → 生成报告"串成一条完整链路,而不是只做中间的分割。

---

### 问题 7:病人半年后复查,两次扫描对不上

**临床场景**:疗效随访要比较同一个器官在不同时间点变大还是变小。但两次扫描的姿态、扫描参数都不同,直接相减毫无意义。

**技术挑战**:
- 需要一个"把两张图对齐"的形变场
- 衡量"对齐得好不好"用什么相似性度量?两幅 CT 的强度关系非线性,MSE 并不合适
- 形变场如果不满足平滑性和可逆性,配准就没有医学意义

**要学的内容**:
- 空间变换网络(用网络学出变换参数)
- MSE 相似度 vs **互信息**相似度
- 变换场的连续性、可逆性陷阱
- Jacobian 场可视化(这是配准结果好坏的唯一可信证据)
- 经典 Demons 方法作为基线对照

**数据**:脑 MRI(OASIS)
**交付物**:配准流水线 + 变换场可视化
**学完之后能干什么**:做纵向对比、配准引导的分割、多模态融合前的空间对齐。

---

### 问题 8:一张病理切片十万像素宽,显卡装不下

**临床场景**:判断一张切片里有没有淋巴结转移,医生需要看整张切片,耗时几十分钟。

**技术挑战**:
- 全切片图像是**多分辨率金字塔**,单张缩略图看不清,单层原图装不下
- 只有切片级标签(有转移/无转移),没有像素级标注 —— 弱监督
- 病灶在整张切片里占比极低

**要学的内容**:
- 金字塔图像的多级读取
- patch 采样策略(高倍区找病灶,低倍区看全局)
- **多实例学习**:切片级标签如何监督到 patch 上(注意力池化)
- 弱监督产出的伪标签如何反哺 patch 级模型
- 注意力热图 —— 让医生能"看懂模型在看哪"

**数据**:淋巴结病理切片标注(坐标 + 标签)
**交付物**:多实例学习模型 + patch 级肿瘤检测
**学完之后能干什么**:进入计算病理方向,掌握弱监督这一范式 —— 它不只用于病理,在标注稀缺的任何任务上都适用。

---

### 问题 9:需要一个连续的风险分数,而不是"有/没有"

**临床场景**:用脑结构预测年龄、评估发育状况、辅助认知障碍诊断。

**技术挑战**:
- 连续标签,损失与评价指标都和分类不同
- **协变量泄漏**:性别、年龄本身可能与标签强相关,模型会走捷径,指标虚高但没有任何医学价值
- 这是医学影像研究里最隐蔽、也最常见的实验陷阱

**要学的内容**:
- 回归网络与损失(MSE / MAE / Huber)
- 回归评价指标(MAE、RMSE、相关系数)
- 协变量泄漏的诊断实验(怎么设计一个能暴露泄漏的实验)
- 特征的归一化与分布对齐

**数据**:脑 MRI(IXI)
**交付物**:三维回归模型 + 泄漏诊断实验报告
**学完之后能干什么**:影像组学与预测建模的基本功,以及识别"看起来很好其实是假的"的模型。

## 七、阶段四· 标注专家只有一个小时

### 问题 10:标注是需要时间的稀缺资源

**临床场景**:三甲医院有经验丰富的标注医生,基层医院没有;研究机构做大规模标注更是天价。**有标签的数据永远是少数。**

**要学的内容**:

**自监督预训练(D22、D24)**
- 掩码建模:遮住 75% 的图像块让模型猜回来
- 对比学习:让同一张图的不同增强互为正样本
- **重点是验证**:自己预训练的权重,微调后到底涨多少?要多次重复实验 + 统计检验

**生成模型(D23)**
- 扩散模型的正向过程(加噪)与反向过程(去噪)
- 噪声调度表、去噪网络、采样器
- 条件控制:用分类器引导 / 无分类器引导
- VQ-VAE 与隐空间扩散
- **生成质量的评价陷阱**:只看 FID 不够,生成的解剖结构可能不合理 —— 需要医学常识判断

**交互式修正(D25)**
- 点提示 / 框提示怎么变成网络特征
- promptable 分割的轻量实现
- 与阶段二的 U-Net 结合

**科研规范(D26)**
- 消融实验怎么设计才有说服力
- 结果差异需要多少重复实验才算显著
- 模型导出与推理一致性验证

**数据**:合成数据 + 阶段一/二已有数据

**交付物**:
- 自监督预训练 → 微调的**增益量化**(不是"感觉变好了",而是"涨了几个点")
- 一个可控的生成模型 + 生成结果分析
- 科研规范清单的实践记录

**学完之后能干什么**:面对小样本任务有一整套可迁移的应对策略 —— 这是从事研究型工作的核心生存技能。

### 选题库(每人独立完成一个)

**A. 分割方向**

| 题目 | 数据 | 基线 | 改进方向 |
|---|---|---|---|
| 稀疏小目标分割 | 脾脏 CT | 3D U-Net | 前景感知采样 / Focal-Tversky / 深监督 |
| 多器官极不平衡分割 | 全身 CT | 3D U-Net | 类平衡损失 / 器官级两阶段 |
| 嵌套标签的训练与评估 | 脑肿瘤 MRI | U-Net | 嵌套区域解耦损失 |
| 滑窗推理策略的系统性研究 | 脾脏 CT | 3D U-Net | 高斯融合 vs 均值 vs 最大,窗口尺寸消融 |
| 边界损失的价值验证 | 脾脏 CT | U-Net | Dice 提升有限但 HD95 显著改善 |
| 跨模态迁移 | 脾脏 → 脑肿瘤 | 3D U-Net | 冻结/微调策略矩阵 |

**B. 效率方向**

| 题目 | 数据 | 改进方向 |

**C. 生成与自监督方向**

| 题目 | 数据 | 改进方向 |

| 题目 | 内容 |
